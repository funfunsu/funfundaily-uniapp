## 使用建议

- **平台调性**：小红书用户反感硬广。文案全程第一人称"我"，只讲我遇到的问题 + 我怎么解决的 + 体验细节，**不出现"功能强大""一键搞定"这类广告词**，不直接报小程序全名做标题党，把名字放在正文自然带出。
- **配图思路（运营自配）**：
  1. 微信里收到的"信封"分享缩略图（带蜡封、「XX 亲启」）——最出片，建议做封面；
  2. 点开后信封展开、文字逐字浮现的录屏切几帧；
  3. 创建表单截图（6 种卡片风格选择那一排）；
  4. 受邀人那边"🔔 活动信息有更新"的变更提示截图——这是差异化卖点。
- **话题标签**：每篇结尾已附 5~6 个标签，可按当下热门话题微调。
- **发布节奏**：主推文（01）先发；02、03 作为不同人群的补充篇错峰发，互相不撞场景。

## 真实感来自这些细节（写文案时别丢）

- 选完开始时间，结束时间会**自动 +2 小时**预填，少填一步；
- 分享出去是**信封**而不是冷冰冰的链接，封面写着「对方称呼 亲启」；
- 受邀人点开**信封自己会拆**，正文像写信一样一个字一个字浮出来；
- 地址行有**「复制」按钮**，对方复制直接去导航；
- 主办方改了时间/地点，已"收下"的人会**自动收到变更记录**，不用挨个重发；
- 邀请函是**私密消息**，发给谁谁才能看，**不能转发朋友圈**；
- 收下的邀请会自动进对方的**日程**，到点有数。
