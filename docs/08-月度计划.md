# 月度计划

## 功能简介

月度计划是**长周期事项规划工具**：在日历式视图上纵览全年（乃至多年）每个月要做的大事，避免遗漏季度性/年度性事项。支持「一次性计划」（某年某月）与「每年重复计划」（每年某月）。属于 `subPackages/monthly-plan` 分包。

相关代码：[subPackages/monthly-plan/pages/list/index.vue](../src/subPackages/monthly-plan/pages/list/index.vue)

## 使用场景与流程

### 场景 1：浏览全年计划
1. 打开页面默认滚动到「今年」，显示年份分隔头（如 2026 年）。
2. 每年展开 12 个月行，每行显示该月的计划卡片。
3. 上滑自动加载前一年、下滑加载后一年（双向无限滚动）；顶部有「回到今年」。

### 场景 2：添加一次性计划
- 点某月的「＋」/「在 X 月添加」→ 底部弹层选「一次性」类型 → 选年-月（前 5 年至后 30 年）→ 填计划名、备注 → 保存。

### 场景 3：添加每年重复计划
- 选「每年」类型 → 选「每年的第 X 月」→ 填计划名 → 保存后该计划在记录范围内每年的该月都出现（约向后 20 年）。

### 场景 4：编辑 / 删除
- 点卡片弹窗改名称/类型/日期/备注；一次性改为每年后所有年份同步。删除需确认。

## 关键字段

| 字段 | 说明 |
|------|------|
| `itemType` | 固定 `monthlyPlan` |
| `itemTitle` / `itemDesc` | 计划名 / 备注 |
| `repeatType` | `none`（一次性）/ `yearly`（每年） |
| `startTime` / `repeatStartDay` / `repeatEndDay` | 一次性绑定具体年月；每年只关心月份，由系统在约 20 年范围内各年展开 |

数据通过 `schedule.save` / `schedule.delete` 操作，`scheduleItemType: 'monthlyPlan'` 拉取。

## 交互特色

- **年份无限滚动**：默认加载去年/今年/明年三块，滚到边界自动续接。
- **月份轨道**：左侧月份号形成纵向导轨，当月蓝色标注、空月份浅灰。
- **类型徽章**：一次性📌 / 每年🔁 小徽章快速区分。
- **类型切换互斥**：选「一次性」显示年-月选择器，选「每年」显示选月列表。
- **就地添加**：每月下方「＋ 在 X 月添加」预填当月。

## 与其他功能的关系

- **群组 / 成员**：归属群组（`groupId`）与成员（`targetUserId`），各成员独立。
- **记录事件**：同为长周期工具，但月度计划是「逐月事项规划」，事件是「纪念日计数」（见 [记录事件](07-记录事件.md)）。
- 复用 schedule_item 体系，不会自动生成任务/日程。
