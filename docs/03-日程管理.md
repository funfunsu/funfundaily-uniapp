# 日程管理

## 功能简介

日程是群组级、多成员、支持重复与分享的**时间规划系统**，对应底部「日程」Tab。以**周视图日历**直观展示每天的时间块，支持创建一次性/重复日程、按群组与成员筛选、把日程分享给他人并被对方「收下」。

## 使用场景与流程

### 场景 1：查看日程（主页）
1. 打开「日程」Tab，自动加载当前周（周一至周日）的日程。
2. 以周视图日历呈现：左侧时间轴（约 8:00–23:00，每行 1 小时），右侧按天分列。
3. 日程块按 `startTime`/`endTime` 精确定位与计算高度，直观展示时间跨度。
4. 不同成员的日程用不同颜色区分，当前登录用户统一为蓝色。
5. 底部固定栏提供「群组选择器 + 成员选择器」，可翻周（上一周/下一周）、回到今日。

### 场景 2：创建日程
1. 点击「添加事件」或直接点日历的某个时间格子（自动预填日期与开始时间）。
2. 填写标题（必填）、描述、地点。
3. 选择模式：
   - **重复（Habit）**：选重复类型（每天/每周/每月/每年）、重复至日期、时间范围；每周还需勾选星期几。
   - **不重复（Todo）**：指定日期，时间可选。
4. 选择分类标签（如「学校」「家里」）。
5. 保存后同步到对应群组与成员，返回主页刷新。

### 场景 3：编辑 / 删除日程
1. 点击日程块进入编辑页，加载全部信息。
2. 修改任意字段后保存；编辑已有日程时显示「删除」按钮。
3. 操作后返回主页自动刷新。

### 场景 4：按群组 / 成员筛选
1. 底部「群组选择器」选某群组（或「我所有的日程」看跨群组全部）。
2. 「成员选择器」选群组内成员（默认当前登录用户，显示为「我」）。
3. 列表实时刷新，只显示该成员在该群组的日程。

### 场景 5：分享日程
1. 主页点「分享」进入分享模式，日程块右上角出现选择框。
2. 多选 / 全选 / 反选要分享的日程，点「去分享」。
3. 后端 `api.share.create()`（场景码 `schedule_share`）生成 `token`，触发微信原生分享。

### 场景 6：收下他人分享的日程
1. 打开分享链接 `pages/schedule/share?token=...`，先用 `shareToken` 自动登录。
2. 页面按日期分组展示被分享的日程。
3. 选目标群组与成员，点「收下」→ `api.schedule.copy()` 复制到该成员；也支持「新成员收下」即时建成员。

## 关键字段

| 字段 | 说明 |
|------|------|
| `itemTitle` / `itemDesc` | 标题（必填）/ 描述 |
| `location` | 地点 |
| `startTime` / `endTime` | 开始 / 结束时间 |
| `itemType` | 类型：`schedule`（普通日程）、`invRecv`（收到的邀请）等 |
| `itemLabel` | 分类标签（school / home 等） |
| `repeatType` | `none` / `daily` / `weekly` / `monthly` / `yearly` |
| `repeatStartDay` / `repeatEndDay` | 重复起止日期 |
| `repeatKeys` | 重复细节：周几（weekly）、几号（monthly）、月-日（yearly） |
| `extra.taskType` | `Habit`（习惯）/ `Todo`（待办） |
| `extra.score` | 完成可得积分 |
| `userId` / `groupId` | 归属成员 / 群组 |

## 交互特色

- **智能结束时间**：改开始时间时，按上次设置的时长（默认 45 分钟，本地缓存）自动推算结束时间。
- **重复规则级联**：切换重复类型时自动填充 `repeatKeys`（如切到每周自动勾当前星期），重复时长本地缓存复用。
- **分享去重**：分享时自动去重，保证接收端数据一致。
- **邀请函只读联动**：当日程 `itemType` 为收到的邀请（`invRecv`）时，点击打开邀请函详情页（只读），而非编辑页。
- **缓存记忆**：群组/成员列表本地缓存，上次选择的群组与成员下次自动恢复。

## 与其他功能的关系

- **群组 / 成员**：日程绑定到「群组 + 成员」二元组，跨群组完全隔离。
- **邀请函**：收到的邀请以 `invRecv` 形式出现在日程里，点开走邀请函预览（见 [邀请函](06-邀请函.md)）。
- **任务打卡**：日程偏「时间块」，任务偏「做没做」；二者数据模型相近（都基于 schedule_item），完成状态通过打卡接口更新 `lastCompleteTime`，由 [scheduleEnricher.ts](../src/utils/scheduleEnricher.ts) 补充「本次是否完成」等派生字段。
- **积分**：`extra.score` 与积分体系联动，完成可得分。
