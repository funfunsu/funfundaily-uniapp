# 任务打卡

## 功能简介

任务打卡是面向家庭的**任务管理 + 积分激励**系统，对应底部「打卡」Tab。家长与孩子约定任务目标，通过日常打卡完成获得积分，进而养成习惯。核心闭环：**制定任务 → 日常打卡 → 赚取积分 → 兑换奖励**。

## 使用场景与流程

### 场景 1：查看今日任务
- 顶部统计卡片：今日「已完成 / 总数」、「总积分余额」、「今日得分」。
- 任务按所关联的**目标（Goal）**分组展示；点目标标题可跳到该目标的日历。
- 任务卡片显示标题、描述、类型标志、打卡次数、积分、截止日期。
- 点任务标题 → 进打卡日历看历史；点编辑按钮 → 底部弹层编辑/删除；点勾选框 → 打卡。

### 场景 2：新建 / 编辑任务
点「添加任务」打开底部弹层（`TaskEditSheet`）。表单包含：
- 标题（必填）、描述。
- **任务类型**（三选一，见下）。
- 关联目标（`parentId`，可不关联）。
- 重复规则（仅习惯）：每天/每周（选星期）/每月（选几号）/每年（选月日）。
- 打卡次数 `totalCount`、积分 `score`、截止日期。

### 场景 3：打卡完成
1. 勾选任务勾选框 → 发送打卡请求（`/api/checkin/task/complete`）。
2. 后端记录完成时间与计数。
3. 前端实时更新：打卡次数（如 1/3 → 2/3）、达标后标题置灰加删除线、积分余额 +`score`、今日得分累加。

### 场景 4：任务分享与收下
- **分享**：进分享模式 → 多选任务 → 「去分享」→ 后端生成 `token` + 小程序码（base64）→ 用 Canvas 画出长图海报（任务清单 + 分享者名 + 小程序码）→ 保存或转发。
- **收下**：好友扫码/点链接进 `pages/task/share` → 自动登录、加载清单 → 选要收下的任务 → 弹「成员选择弹窗」选已有成员或新建成员 → 后端复制任务（清空 id/parentId 避免冲突）。

### 场景 5：任务日历 vs 打卡日历
| 维度 | 任务日历 (`task/calendar`) | 打卡日历 (`task/checkin-calendar`) |
|------|---------------------------|-----------------------------------|
| 数据源 | 任务定义（截止日 + 重复规则展开） | 后端真实打卡记录（`taskTime`） |
| 展示 | 每日应做多少任务（待做/已截止） | 每日实际完成了哪些、打卡几次 |
| 操作 | 可新增/编辑/删除任务 | 只读（回顾历史成果） |

## 任务类型

| 类型 | 用途 | 要点 |
|------|------|------|
| **Habit 习惯** | 反复打卡养成习惯 | 支持重复周期 + 每周期打卡次数 `totalCount`；每周期重置计数，达标即完成 |
| **Todo 待办** | 一次性任务 | 只需截止日期，勾选即完成，不支持多次打卡 |
| **Goal 目标** | 长期目标，作为分组容器 | 本身不能打卡；其他任务通过 `parentId` 挂到它下面，主页按目标分组 |

## 关键字段

| 字段 | 说明 |
|------|------|
| `itemTitle` / `itemDesc` | 标题 / 描述 |
| `extra.taskType` | `Habit` / `Todo` / `Goal` |
| `extra.totalCount` | 单周期需打卡次数（习惯） |
| `extra.score` | 每次打卡可得积分 |
| `repeatType` / `repeatKeys` | 重复规则及细节 |
| `repeatStartDay` / `repeatEndDay` | 重复起止 |
| `parentId` | 关联目标 ID（0 表示不关联） |
| `recordExtra.count` | 当日已打卡次数（合并打卡记录得到） |
| `showExtra.itemKey` | 周期实例键，用于匹配打卡记录、判断是否已完成 |

工具函数：`isTaskUndo()` 判断是否未完成；`sortTaskToShow()` 排序（未完成优先、截止早优先）。

## 新手引导

首次进入或当日无任务时展示引导卡片：🎯「开启你的任务打卡之旅 · 完成任务 / 赚取积分 / 养成好习惯」，三个亮点（📝制定任务计划、✅打卡完成赚积分、🎁积分兑换奖励），CTA「+ 创建第一个任务」直接打开新增弹层。

## 与其他功能的关系

- **目标 Goal**：N 个任务挂到 1 个目标，主页按目标分组，点目标看其日历。
- **成员**：任务归属某成员（`targetUserId`），不同成员各有清单；只有所有者可编辑/删除，他人可查看/打卡。
- **积分**：打卡得分 → 积分余额累加，到[积分兑换](05-积分兑换.md)消耗。
- **分享 / 收下**：与日程分享同源，但任务分享走「长图海报 + 小程序码」，收下走成员选择弹窗（可新建成员）。
- **群组**：所有任务/积分按群组隔离。
