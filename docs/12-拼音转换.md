# 拼音转换

## 功能简介

把中文汉字快速转换为拼音，方便家长教学与儿童学习标准发音。属于 `subPackages/study-tools` 分包。

相关代码：[subPackages/study-tools/pages/writing/pinyin-converter.vue](../src/subPackages/study-tools/pages/writing/pinyin-converter.vue)

## 使用场景与流程

1. 进入页面，在输入框输入一个或多个汉字（如「你好世界」）。
2. 页面**实时**转换并显示拼音，以空格分隔（如 `ni hao shi jie`）。
3. 清空输入框时结果与错误提示自动清空。

## 关键实现

- 使用 `pinyin-pro` 库的 `pinyin()`，配置 `{ type: 'array' }` 后 `join(' ')`。
- `watch` 监听输入变化自动触发转换（`immediate: false`），无需点按钮。
- `try-catch` 容错：异常时提示「转换出错，请检查输入。」；空输入清空结果。

## 与其他功能的关系

- 与[汉字笔顺学习](11-汉字笔顺学习.md)联动：笔顺页选字后也会调用该转换显示拼音。
- 相对独立，主要依赖 `pinyin-pro` npm 库。
