# 发现页与更多

## 功能简介

「更多」Tab 是一个**后端驱动的功能入口聚合页（发现页）**，把积分、财务、学习、工具等各类功能按分类聚合展示。条目由后端下发，便于灵活上下线功能而无需改前端代码。

相关代码：
- 页面：[pages/tabBar/more.vue](../src/pages/tabBar/more.vue)
- 路由跳转：[utils/router.ts](../src/utils/router.ts)

## 使用场景与流程

1. 打开「更多」Tab，调 `api.discovery.list()` 拉取条目列表。
2. 前端按 `category` 分组成若干白色圆角卡片，每组内 4 列网格展示条目。
3. 点击条目按其类型跳转：
   - `path` / `tab`：若 `uri` 含 `/tabBar/` 用 `switchTab` 切 Tab；否则 `navigateTo` 压栈跳转。
   - `link`：暂不支持外链（提示「功能暂未开放」）。
   - 状态非 `active` 的条目显示「即将开放」，不可点击。

## 条目数据结构（`DiscoveryItem`）

| 字段 | 说明 |
|------|------|
| `itemTitle` | 显示标题 |
| `itemType` | `path`（小程序路由）/ `tab`（Tab 切换）/ `link`（外链） |
| `uri` | 目标地址 |
| `status` | `active` / `inactive`（禁用显示「即将开放」） |
| `category` | 分类（积分中心 / 家庭财务 / 学习成长 / 生活工具） |
| `icon` | emoji 图标，缺省时用标题首字 |

## 分类与配色

前端按既定顺序展示分类，每类配一种主题色；无分类条目归入兜底分组「更多功能」：

| 分类 | 配色 |
|------|------|
| 积分中心 | amber `#f59e0b` |
| 家庭财务 | green `#10b981` |
| 学习成长 | blue `#3b82f6` |
| 生活工具 | purple `#8b5cf6` |
| 更多功能（兜底） | gray |

## 数据维护约定

> 发现页条目**只在后端 `data.sql` / `script/update_sql.sql` 维护**（yml 里的 `app.discovery.items` 是死配置，不用它），**不要在 `more.vue` 里 hardcode**。条目通过 `category`/`icon` 字段用于「更多」页的分组与图标展示。新增功能入口时在后端 SQL 加一条记录即可。

## 与其他功能的关系

- 是积分兑换、理财计划、月度计划、记录事件、邀请函、学习工具等分包功能的统一入口。
- 「我的」Tab 承载账号、群组管理、创建群组、联系开发者等（见 [登录与账号](01-登录与账号.md)、[群组与成员管理](02-群组与成员管理.md)）。
