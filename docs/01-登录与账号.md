# 登录与账号

## 功能简介

用户首次进入小程序通过**微信授权**完成登录，系统据此创建/识别账号并发放访问令牌。登录后可设置/修改昵称，作为在各群组中展示的身份名。

相关代码：
- 登录页 / 昵称设置：[pages/index/index.vue](../src/pages/index/index.vue)
- 自动登录逻辑：[utils/auth.ts](../src/utils/auth.ts)
- 令牌存取：[utils/token.ts](../src/utils/token.ts)

## 使用场景与流程

### 场景 1：微信授权登录
1. 打开小程序进入登录页，调用 `uni.login()` 获取微信 `code`。
2. 将 `code`（以及分享链接里携带的 `shareToken`，若有）发送到后端 `/login`。
3. 后端校验后返回 `ACCESS_TOKEN`，前端保存到本地存储（key：`ACCESS_TOKEN`）。
4. 登录成功后自动调用 `getInfo()` 拉取用户信息（id、昵称、头像等）。

### 场景 2：昵称设置 / 修改
1. 登录后检查账号状态：若账户**创建已超过 7 天但仍未设置昵称**，强制进入昵称设置页。
2. 用户可「提交」昵称，或选择「我先逛逛」跳过。
3. 昵称也可后续在「我的」页面随时修改（弹窗输入 → `api.user.update()`）。

### 场景 3：登录后的跳转
- 普通进入：完成后跳转到首页（日程 Tab）。
- 通过分享链接进入：携带 `redirectPath`，登录后重定向到对应的分享页（日程分享 / 任务分享 / 邀请函 / 群组邀请等）。

## 关键概念

- **ACCESS_TOKEN**：用户身份令牌，存于本地存储，后续所有接口请求携带。
- **shareToken**：分享链接里的临时令牌，可用于免登录预览分享内容，并在登录时关联来源。
- **昵称**：账号在群组中展示的名称，未设置时以首字作头像占位。

## 与其他功能的关系

- 登录是所有功能的入口；登录后才会有可用的群组与成员上下文。
- 分享相关功能（日程分享、任务分享、邀请函、群组邀请）都依赖 `shareToken` 在登录环节衔接，让被分享者无缝进入对应页面。
- 登录后由 [utils/currentGroupResolver.ts](../src/utils/currentGroupResolver.ts) 自动解析「当前群组 / 当前成员」，供各业务页面使用（详见 [群组与成员管理](02-群组与成员管理.md)）。
