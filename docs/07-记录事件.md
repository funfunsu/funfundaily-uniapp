# 记录事件

## 功能简介

记录事件是**纪念日 / 里程碑追踪工具**：记录生日、恋爱/结婚纪念日、宝宝出生、入职、搬新家等重要时刻，系统自动计算「已经过了第 X 年 X 月 X 天」，让日子过得有盼头。支持按目标分类、照片加水印分享、停止/恢复关注。属于 `subPackages/event` 分包。

相关代码：[subPackages/event/pages/event/index.vue](../src/subPackages/event/pages/event/index.vue)

## 使用场景与流程

### 场景 1：快速创建常见事件
- 空状态展示常见事件模板（生日、恋爱纪念日、结婚纪念日、宝宝出生、入职、搬新家）。
- 点模板（如「生日」）→ 事件名预填、时间预填今天，在底部弹层微调时间、选目标、加备注后保存。

### 场景 2：自定义创建
- 点「+ 添加事件」/「+ 自定义创建」，输入事件名、选事件时间、选所属目标，保存。

### 场景 3：查看与筛选
- 事件按开始时间倒序展示，每张卡片显示事件名、开始时间、「已经第 X 年 X 月 X 天」。
- 顶部目标筛选栏（全部 / 各目标 / 未分类），点 chip 即时过滤。
- 30 天内的近期事件卡片边框高亮、带渐变装饰。

### 场景 4：详情与分享
- 点卡片 → 底部弹层显示详情（开始时间、已开始天数、所属目标）。
- 「照片分享」打开水印相机，拍照并叠加「事件名 + 已过天数」水印，可分享到朋友圈/微信。

### 场景 5：停止 / 恢复关注
- 详情里「停止关注」→ 事件隐藏（状态置 `CLOSED`，非删除）。
- 列表顶部显示「已停止关注 X 个」，进入可「恢复关注」（状态回 `OPEN`）。

## 关键字段

| 字段 | 说明 |
|------|------|
| `itemTitle` | 事件名（如「宝宝出生」） |
| `itemType` | 固定 `event` |
| `startTime` / `repeatStartDay` | 事件发生时间 |
| `repeatEndDay` | 向后约 20 年，保证长期追踪 |
| `parentId` | 关联目标 ID（分类维度） |
| `status` | `OPEN` / `CLOSED`（通过 `schedule.close` 切换） |
| `daysDesc` | 前端计算的「第 X 年 X 月 X 天」 |

天数计算（`calcDaysDesc`）：按年/月/日差计算并处理退位，年数>0 时输出「第 X 年 X 个月 X 天」，否则输出「第 N 天」。

## 交互特色

- **新用户模板引导**：空状态即提供预填模板，降低创建门槛。
- **近期高亮**：30 天内事件视觉突出。
- **目标分类筛选**：动态展示各分类及数量，点击即时刷新。
- **停止≠删除**：可隐藏后恢复，数据保留。
- **水印拍照分享**：集成 `WatermarkCamera`，照片自带事件名 + 天数水印。

## 与其他功能的关系

- **目标 Goal**：事件可挂到某个目标（`parentId`）做分类。
- **群组 / 成员**：事件归属群组与成员（`targetUserId`），各成员独立。
- **月度计划**：同为长周期规划工具，但本功能是「纪念日计数」，月度计划是「逐月事项规划」（见 [月度计划](08-月度计划.md)）。
- 数据通过 `schedule.save` / `schedule.close` 操作，复用 schedule_item 体系。
