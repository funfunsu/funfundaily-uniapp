# 积分兑换

## 功能简介

积分兑换是配合任务打卡的**家长—孩子激励闭环**：家长配置奖励目录（兑换品），孩子用打卡攒下的积分兑换奖励。属于 `subPackages/points` 分包。

相关代码：
- 兑换品管理：[subPackages/points/pages/points-product-manage.vue](../src/subPackages/points/pages/points-product-manage.vue)
- 兑换品编辑：[subPackages/points/pages/points-product-edit.vue](../src/subPackages/points/pages/points-product-edit.vue)
- 积分兑换：[subPackages/points/pages/points-exchange.vue](../src/subPackages/points/pages/points-exchange.vue)
- 兑换记录：[subPackages/points/pages/points-exchange-records.vue](../src/subPackages/points/pages/points-exchange-records.vue)

## 使用场景与流程

### 场景 1：家长配置奖励（兑换品管理）
1. 打开「兑换品管理」，看到价值引导卡片 + 常见奖励的一键快速添加（如「看 30 分钟动画」「10 元零花钱」）。
2. 或点「添加」进编辑页，手动填写：名称、所需积分、描述。
3. 保存后以网格展示在管理页。

### 场景 2：孩子兑换奖励
1. 打开「积分兑换」，顶部为积分余额卡片（含「去打卡」引导）。
2. 下方展示家长配置的可兑换商品网格。
3. 点商品 → 弹窗确认「是否用 X 积分兑换」→ 确认后扣分，余额实时更新。
4. 积分不足时兑换按钮灰显并提示「积分不足」。

### 场景 3：查看兑换记录
- 从积分卡片的「兑换记录」入口进入，纵向列表展示每次兑换：商品名、时间、扣除积分、兑换后余额；支持无限下拉分页加载（每次约 20 条）。

## 关键字段

| 字段 | 说明 |
|------|------|
| `product.name` | 商品名称（如「看 30 分钟动画片」） |
| `product.description` | 商品说明 |
| `product.requiredScore` / `points` | 兑换所需积分 |
| `balance` | 成员当前积分余额 |
| `record.scoreDeducted` | 本次扣除积分 |
| `record.balanceAfter` | 兑换后余额 |
| `record.exchangeTime` | 兑换时间 |

积分本质是一种「流」（`flowType: POINTS`），后端通过流账户查询余额与变动。

## 交互特色

- **预设模板快速创建**：家长首配无需想象，点芯片一键添加常见奖励，可再微调。
- **分角色视图**：管理页是「配置视角」（名称/描述/积分），兑换页是「用户视角」（够不够分）。
- **积分不足禁用**：买不起的商品按钮灰显。
- **分页加载**：兑换记录无限滚动，避免一次加载卡顿。

## 与其他功能的关系

- **任务打卡**：积分的唯一来源是完成任务打卡（见 [任务打卡](04-任务打卡.md)）；兑换是积分的消耗端。
- **群组**：每个群组独立配置自己的奖励目录，按 `groupId` 隔离。
- **成员**：积分余额是成员维度，兑换需指定成员。
- **理财计划/账本**：均为独立的财务/流账户体系，与积分不互通。
