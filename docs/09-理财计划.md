# 理财计划

## 功能简介

理财计划是**多层次的投资目标与执行跟踪系统**，覆盖从「我的投资目标多少」→「计划怎么分类投资」→「实际怎么一步步交易」→「赚了多少」的完整链路。支持美股/港股/A 股多市场、目标盈利对标、批次交易跟踪与已实现收益统计。属于 `subPackages/financial-plan` 分包。

## 数据层级

```
计划 FinancialPlan
 └─ 标的 Asset（一只股票，属某市场）
     └─ 批次 RealizationBatch（一次建仓计划，正股/衍生品）
         └─ 交易操作 Operation（买入/卖出，可多次）
```

## 使用场景与流程

### 场景 1：创建理财计划
- 点「新建计划」→ 填计划名、时间范围（年度 / 自定义起讫）、目标盈利、备注 → 保存。列表默认按截止日倒序（进行中靠前）。

### 场景 2：添加标的与批次
1. 展开计划卡片，查看目标盈利、已计划、已实现 + 各市场汇率明细。
2. 点「+ 标的」填股票名、选市场、目标盈利。
3. 标的内「+ 批次」选类型（正股/衍生品）、数量、预期买/卖价；衍生品另选方向（CALL/PUT/Short-CALL/Short-PUT）与到期日。

### 场景 3：记录交易、跟踪进度
- 批次「买入」填实际买入价/数量/手续费/日期，状态：待买入 → 已买入 → 待卖出。
- 「卖出」后批次标记「已完成」，实际盈利 =（卖出价 − 买入价）× 数量 − 手续费。
- 计划级「已实现收益」自动累加所有已完成批次的实际盈利。

### 场景 4：编辑与归档
- 结束日期前可编辑计划/批次、删除资产；结束后自动只读、状态「已结束」。可手动「归档/恢复」。

## 关键概念与字段

- **FinancialPlan**：`planName`、`timeRangeType`（YEAR/CUSTOM）、`fiscalYear`、`startDate`/`endDate`、`targetProfit`、`actualProfit`、`completionRate`、`status`（ACTIVE/ARCHIVED/DRAFT）。
- **Asset**：`stockName`、`market`（US/HK/CN）、`targetProfit`、`sequenceNo`。
- **RealizationBatch**：`batchType`（EQUITY/DERIVATIVE）、`direction`、`quantity`、`planBuyPrice`/`planSellPrice`、`stageStatus`（PENDING_BUY/PARTIAL_BOUGHT/PENDING_SELL/COMPLETED）、`actualBuyPrice`/`actualSellPrice`/`actualProfit`、`feeTotal`、`expirationDate`。
- **Operation**：`operationType`（BUY/SELL）、`tradeDate`、`price`、`quantity`、`fee`。
- **ProfitSummary**（后端聚合）：`targetProfit`、`plannedProfit`（各批次目标收益之和）、`actualProfit`、`completionRate`、`plannedCompletionRate`。
- **汇率**：固定 USD 7.2 / HKD 0.92 / CNY 1，计划级别按市场分组展示原币种 + 汇率，而非直接折算累加。

## 交互特色

- **多货币明细**：一个计划可同时投美/港/A 股，按市场展示原币种 + 汇率，直观看跨市场组合。
- **进度条可视化**：计划头部进度条宽度 = 完成率，正盈利绿/负盈利红/中性蓝。
- **批次多阶段流转**：待买入→已买入→待卖出→已完成，各阶段按钮规则不同。
- **乐观并发**：每条记录带 `version` 字段。

## 与其他功能的关系

- **群组 / 成员**：计划归属群组（`groupId`），有创建者（`ownerUserId`，通常是家长）。
- **与积分/任务无关**：理财是独立的投资跟踪系统，与积分激励、账本现金流均为平行体系。
