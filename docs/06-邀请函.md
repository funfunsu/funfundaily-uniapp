# 邀请函

## 功能简介

邀请函让用户快速制作**精美的电子邀请卡**，用于向家人/朋友分享活动信息（聚会、生日会等）。制作方自定义卡片风格与内容并分享，受邀人可「收下邀请」保存到自己的邀请函列表；若原邀请的时间/地点变更，受邀人会收到变更通知。属于 `subPackages/invitation` 分包。

## 使用场景与流程

### 场景 1：创建并分享邀请函
1. 进入邀请函列表（默认「我创建的」Tab），点「新建」。
2. 填写：活动标题、起止时间、地址、邀请正文、落款人；从 6 种卡片风格中选一种并实时预览。
3. 保存后回列表，点卡片的「邀请」按钮，输入受邀人称呼。
4. 分享时系统离屏画布生成精美「信封」缩略图（含渐变背景、蜡封圆章、「某某 亲启」字样），通过微信分享给好友；后端生成分享 `token`。

### 场景 2：接收并收下邀请
1. 受邀人点链接进 `preview` 页，看到「关闭的信封」动画自动展开，内容逐字浮现（打字机效果）。
2. 点「收下邀请」将邀请关联到自己账户，保存为「我收到的」记录。
3. 在「我收到的」Tab 查看。

### 场景 3：查看收到的邀请与变更
- 「我收到的」Tab 点邀请函 → 只读详情。
- 若原邀请的时间/地点改过，列出变更记录（时间戳 + 摘要）；有变更的邀请在 Tab 上显示红点。

### 场景 4：编辑 / 删除已创建的邀请
- 「我创建的」Tab 点「编辑」改内容后保存；若改了时间/地点，后端自动向所有已收下的受邀人发变更通知。
- 「删除」仅删除发出的记录，受邀人各自的收到记录保留。

## 关键字段与存储

`InvitationTemplate` 主要字段：`direction`（sent/received）、`title`、`startTime`/`endTime`、`address`、`body`、`cardStyle`、`signature`、`recipientName`、`parentId`（收到记录指向原发出记录）、`changes`（变更记录数组）。

卡片风格 6 选 1：`classic`（经典蓝）、`playful`（派对欢乐）、`soft`（柔和粉嫩）、`warm`（暖意金棕）、`elegant`（雅致深绿）、`modern`（极简黑白）。

**存储**（见重构说明）：邀请函复用 `schedule_item` 表，不再写 `universal_record`。`item_type` 用短码 `invSent`（发出）/ `invRecv`（收到）；title→item_title、address→location、起止时间→start/end_time、body/cardStyle/signature 等→extra(JSON)；发出记录 `parent_id=0`，收到记录指向原发出记录。

## 交互特色

- **信封拆信动画**：逼真信封展开 + 内容逐字浮现，总时长控制在约 1.2–3.2s（内容越长每帧揭示越多）。
- **写信式排版**：「亲爱的 XX：」→「诚邀你参加『活动』」→ 正文 → 时间 → 地点 → 落款，地址行可一键复制。
- **两种加载模式**：`token` 模式（分享链接，需 shareToken 登录，含完整动画与「我也要制作」引导）；`id` 模式（从日程点开，跳过动画立即展开、只读、展示变更记录）。

## 与其他功能的关系

- **日程**：收到的邀请（`invRecv`）会出现在[日程](03-日程管理.md)里，点开走本页的 `id` 只读模式。
- **群组/成员**：发出的邀请属于某群组，可从成员中选分享对象；收到的邀请跨群可见。页面顶部集成 `schedule-bottom-bar` 切群组。
- **分享系统**：复用通用分享服务（`share.create` / `share.getContent`），靠 `token` 实现免登录预览。
