# 汉字笔顺学习

## 功能简介

帮助儿童学习汉字**笔画与书写顺序**：在交互式 Canvas 画布上逐笔演示汉字写法，支持自动演示、手动步进、重新练习，并显示拼音。属于 `subPackages/study-tools` 分包。

相关代码：
- 页面：[subPackages/study-tools/pages/writing/stroke-order.vue](../src/subPackages/study-tools/pages/writing/stroke-order.vue)
- 笔顺画布组件：[subPackages/study-tools/components/HanziStroke.vue](../src/subPackages/study-tools/components/HanziStroke.vue)
- 笔顺数据：[subPackages/study-tools/stroke-data/index.js](../src/subPackages/study-tools/stroke-data/index.js)

## 使用场景与流程

### 场景 1：学习一个汉字
1. 顶部输入框输入一个汉字（如「你」），点「添加汉字」。
2. 主画布（约 300×300，带米字格）加载并自动演示笔顺（逐笔演画，约 800–1200ms/笔）。
3. 下方显示该字拼音。

### 场景 2：步骤预览与步进控制
- 演示后下方按行展示「书写步骤预览」（每行 4 个小画布，显示每笔完成样子）。
- 「上一步 / 下一步」手动控制主画布进度。

### 场景 3：重新练习
- 全部演示完后弹出「重新书写"某字"」按钮并启动 5 秒倒计时；点击或倒计时结束自动从第一笔重画。

### 场景 4：历史管理
- 顶部维护历史字符列表（水平滚动，最多约 20 个），点历史字可直接切换；「清空」清除历史。

### 场景 5：分享
- 支持微信分享，分享内容含当前字与历史列表；接收者进入时会恢复历史列表继续学习。

## 关键概念

- **笔顺数据**：来自本地预编译字库 `stroke-data` 或后端 `json.get`；结构 `{ strokes: ["M.. L.. Q..", ...] }`，每条为一笔的 SVG 路径（支持 M 移动 / L 直线 / Q 二次曲线）。
- **整字边界 `wholeCharBounds`**：用于自动缩放，使汉字占画布约 80%。
- **米字格**：浅灰十字 + 对角线参考网格，帮助理解笔画位置。

## 交互特色

- **SVG 路径解析**：识别 M/L/Q 命令提取坐标，平滑绘制弯曲笔画。
- **平台适配**：H5 用原生 Canvas 2D（处理 DPR），小程序用 `createCanvasContext` 并手动 `draw()`。
- **倒计时自动重写**：演示结束触发，5 秒后自动重练。
- **分享恢复**：历史列表 `encodeURIComponent` 进 URL，接收端解析还原。

## 与其他功能的关系

- **拼音转换**：选字后调用 `pinyin(char)` 显示拼音（见 [拼音转换](12-拼音转换.md)）。
- **字库可扩展**：本地缺失的字回源后端 API。
- 与日程/任务等核心业务无直接关系，是独立学习工具。
