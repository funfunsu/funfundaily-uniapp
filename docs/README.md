## 产品定位

funfun（小程序内部标识 `fungrowth`，导航标题「funfun日程」）是一款**面向家庭的成长管理小程序**，运行于微信小程序与 H5（uni-app + Vue 3）。它以「群组（家庭）」为单位组织数据，围绕**时间管理 + 习惯养成 + 激励兑换 + 家庭工具**四条主线，帮助家长和孩子一起规划日程、坚持打卡、攒分换奖励，并提供理财、账本、识字等实用工具。

核心闭环：**制定任务/日程 → 日常打卡 → 赚取积分 → 兑换奖励**。

## 基础概念

- **群组（Group）**：一个家庭 / 团队的逻辑容器，所有数据（日程、任务、积分、账本……）都按群组隔离。一个用户可同时属于多个群组。
- **成员（Member）**：用户在某个群组内的身份，带角色（创建者 / 管理员 / 普通成员）。同一份数据可分别归属到不同成员（如「我」「老大」「老二」）。
- **当前群组 / 当前成员**：进入需要 `groupId`/成员的页面时，系统会自动解析默认值（`ensureCurrentGroup` / `ensureCurrentMember`），无需用户每次手动选。

## 导航结构

- **底部 Tab**：日程 · 打卡 · 更多 · 我的
- **更多（发现页）**：按分类聚合「积分中心 / 家庭财务 / 学习成长 / 生活工具」等功能入口，条目由后端下发（见文档 13）。
- **我的**：账号信息、群组列表、创建群组、联系开发者（见文档 01、02）。
- **分包（subPackages）**：积分兑换、理财计划、月度计划、记录事件、邀请函、学习工具（笔顺/拼音/账本）按需加载。
