# 家庭账本

## 功能简介

家庭账本用于记录家庭日常**收支流水并追踪现金余额**，可用于简单家庭财务管理或亲子财商教育。按群组/成员分类管理。属于 `subPackages/study-tools` 分包（学习成长 / 生活工具类）。

- 编辑流水：[subPackages/study-tools/pages/ledger/edit.vue](../src/subPackages/study-tools/pages/ledger/edit.vue)
- 流水项组件：[subPackages/study-tools/components/LedgerItem.vue](../src/subPackages/study-tools/components/LedgerItem.vue)

## 使用场景与流程

### 场景 1：查看账本
- 顶部固定展示当前余额（如 ¥5,234.50）。
- 下方按时间倒序列出流水记录，底部「上一页/下一页」分页（每页约 100 条，不足一页即到底）。

### 场景 2：记一笔收入/支出
1. 点「添加收入」或「添加支出」进编辑页。
2. 输入金额（元，自动限制小数点后两位）、类型、摘要（可选）。
3. 保存：金额转为「分」存储，收入为正、支出为负；返回列表自动刷新余额与记录。

### 场景 3：切换群组/成员
- 底部 `schedule-bottom-bar` 切群组/成员，切换后自动刷新对应账本。

## 关键字段

| 字段 | 说明 |
|------|------|
| `amount` | 金额，单位「分」（整数），收入正/支出负 |
| `balance` | 该笔后的累计余额（分） |
| `description` / `summary` | 摘要 |
| `flowType` | 固定 `CASH`（现金类） |
| `transactionType` | `INCOME`（收入）/ `EXPENSE`（支出） |
| `createdAt` | 流水时间 |
| `groupId` / `targetUserId` | 归属群组 / 成员 |

**金额单位**：前端显示元（¥），存储为分（元 × 100）；入账绿色、出账红色。

## 交互特色

- **金额输入限制**：仅数字与小数点，自动限两位小数、防多个小数点。
- **千分位显示**：金额自动加千分位分隔符并按收支着色。
- **保存后自动刷新**：通过 `REFRESH_TAB` 标记，返回列表 `onShow` 时刷新。

## 与其他功能的关系

- **群组 / 成员**：每条流水属于某群组与成员，列表按二者过滤，底部栏支持切换。
- **独立财务工具**：与积分、理财计划相互独立，各为不同的流账户体系。
- 接口走后端 `flow.balance` / `flow.list` 等，支持分页与多条件过滤。
